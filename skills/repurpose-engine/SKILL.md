# Repurpose Engine

Repurposing is adaptation, not copying. Posting the same content everywhere is cross-posting. Repurposing means understanding what worked and translating it for a different platform's audience, format, and conventions.

## What Stays vs. What Changes

**Stays:** core message, voice, value proposition, key visuals or assets.

**Changes:** format (aspect ratio, duration, structure), hook (platform-specific), caption style, hashtag strategy, CTA, pacing. Sometimes the hook changes entirely — what stops a scroll on TikTok won't stop one on LinkedIn.

## The Adaptation Checklist

For each target platform, run through these:

**Format fit** — does the content work in this platform's native formats? A 10-minute YouTube video doesn't become a sped-up 60-second TikTok. It becomes a highlight clip of the best moment, or a completely re-shot short version.

**Hook translation** — what made people stop scrolling on the source platform? That mechanism might not exist on the target. A YouTube thumbnail+title hook becomes a TikTok text overlay and opening line. A threaded X take becomes a LinkedIn "here's what I learned" post.

**Audience context** — the same person on LinkedIn and TikTok wants different things from the same topic. Professional framing for LinkedIn. Entertainment framing for TikTok. Educational framing for YouTube. The core insight can be identical — the packaging changes.

**Convention check** — load the target platform's reference file (read `.root` for repo path, then `{repo}/references/platforms/{platform}.md`). Does the adapted version feel native? Would someone scrolling past think "this was made for this platform"?

## Repurposing Hierarchy

Create original content where your primary audience lives. Adapt outward from there. Don't try to create original content for five platforms — create for one or two and repurpose to the rest.

The primary platform is wherever you have the strongest audience and the content format that comes most naturally to you.

## Common Repurposing Paths

**Long-form YouTube → TikTok/Reels** — extract the single best moment, most surprising insight, or strongest hook. It's a highlight, not a summary.

**TikTok → Reels** — often works with minimal changes. Remove any TikTok watermark. Check that the caption style fits Instagram. Reels audiences tend to engage with slightly more polished content.

**Video → Carousel** — extract key frames, add text overlays, turn a narrative into a swipeable sequence. Works well for tutorials, listicles, and transformations.

**Thread/text post → Short-form video** — talking head or text-on-screen. The script is already written — you're just changing the delivery medium.

**Any platform → LinkedIn** — add professional context. "I learned this doing X" or "here's why this matters for [industry]." The insight stays; the framing becomes career-relevant.

Load both source and target platform references when repurposing.
